# SIRIUS 履修登録（半自動）

時間割コードを渡すと、SIRIUS「履修登録」(`RSW0001000-flow`) の **コード指定登録** に1件ずつ入れて登録を押し、画面に出たメッセージ（登録しました／重複／上限／存在しません など）を表示する。**最後の「登録完了」ボタンは押さない**。本人がブラウザで履修登録画面を開き、一覧を確かめてから押す。

## コマンド

```bash
cd ~/Projects/sirius-fetch
node register.mjs 02xx0001 02xx0002   # 時間割コードを空白区切りで並べる
```

- 出力は1コードにつき1行: `02xx0001: 登録しました` のように、画面のメッセージから該当行を拾って表示する。拾えなければ `(メッセージなし — 登録状況で要確認)`。
- 所属は工学部（`#jikanwariShozokuCodeSelect` = `02`）固定。他学部の科目を入れる時はコードを直す。
- ダイアログ（確認・警告）は内容をログに出して受け入れる。
- headless で動く（画面は出ない）。セッション切れは `getSession()` が自動ログインで復帰する（`sirius-session`）。

## 時間割コードの調べ方

- 時間割の `code`（例 `02xx0000`）。今学期の登録済み科目は `~/.local/share/sirius-fetch/output/timetable.json`（`sirius-portal` の `node fetch.mjs` が更新）。
- これから登録する科目のコードはシラバス検索（flowId `SBW3701300`）か学科の履修案内で確認する。**コードはユーザーに確認してから実行する**（取り違えると別の科目が登録される）。

## 典型的な流れ（Claude の動き）

1. ユーザーから科目名を聞き、時間割コードを特定してユーザーに確認する
2. `node register.mjs <コード...>` を実行し、各行のメッセージを報告する
3. 「重複」「上限」「存在しません」などが出たコードは理由を伝える
4. 本人に、SIRIUS の履修登録画面で一覧を確かめて「登録完了」を押すよう伝える

## 安全原則

- **「登録完了」は自動で押さない**（必ず本人）。
- 履修登録期間外・抽選科目・定員制の科目は、画面の指示に従って本人が手続きする。
- 削除（登録取消）はこのスクリプトでは行わない。
